# 验收清单

## 本地验证与界限

- 自动测试：`npm test`。
- 配置、JS语法和页面成组检查：`npm run check`。
- 可使用本机微信开发者工具自带 WXML/WXSS 编译器检查全部页面；这只验证编译，不代表模拟器或真机通过。
- 未配置 AppID/云环境时，授权、数据库事务、权限规则、真实码和云存储均不能完成端到端验证。

## 连接云环境后逐项验收

1. 先在独立测试云环境创建全部集合、索引和私有权限，部署云函数；确认公众平台手机号能力和隐私指引正常。
2. 测试一部窄屏设备和一部带底部手势区设备：注册页无横向溢出，按钮可点击，聊天键盘不遮住输入框，管理编辑区可见。
3. 测试注册：选一园区和十园区、性别各选项；拒绝授权后可重试；空昵称不能提交；资料不合法不写入；手机号从微信取得。
4. 断网/云函数未部署/门店不存在：显示恢复提示，无虚假注册成功。首次注册生成恰好一条通知。
5. 已注册用户重新授权登录，不覆盖原资料；授权其他手机号无法登录原账户；相同手机号不能绑定另一微信身份；退出后旧令牌失效。
6. 客户甲不能读取客户乙的资料和消息。门店甲不能读取门店乙客户或消息。通过修改前端角色、OpenID 或门店参数也不能越权。
7. 客户发消息 → 门店列表出现未读 → 门店进入并回复 → 客户收到；关闭/重新打开保留记录。断网后以相同请求编号重试不会重复。
8. 单会话发送35条以上，加载历史无漏条/重复，未读位置不超过实际已显示消息；前后台切换后无重复轮询。
9. 门店打开工作台时注册新客户，15秒左右有提示；未读可标记。未授权订阅时退出小程序后不应期待微信推送。
10. 管理员将测试客户设为门店员工，该客户旧登录态失效，重新登录后只显示对应工作台。启停账户和门店效果正确，审计记录完整。
11. 数据库查看每次只返回20条，用户记录中没有会话哈希；查询非白名单集合被拒绝。使用小程序客户端直接访问数据库一律被规则拒绝。
12. 生成体验版入口码并真机扫描，正确进入门店注册页。正式版发布后再生成正式码；测试失效门店提示。检查小程序热启动扫码和冷启动扫码。
13. 洗护与家政筹备入口无支付/假下单行为；退出账户不会留下客户列表或聊天缓存给其他登录态。

完成后才上传体验版让门店试用。提交审核与发布由拥有权限的运营者确认目标 AppID、版本和环境后执行。

## 2026-09-19 修复回归

- 消息列表加载至少两页，等待自动刷新，确认已加载范围保留；弱网快速切页后无重复轮询。
- 生成超过20条未读通知，标记当前20条后查询后续分页，确认未显示通知仍未读；另一员工的状态不受影响。
- 请求过程中离开聊天页，返回的旧消息不触发已读写入；已读请求失败后能重试。
- 小程序与 api 云函数一并更新后验证通知已读，旧客户端的时间戳写入应返回明确错误。
