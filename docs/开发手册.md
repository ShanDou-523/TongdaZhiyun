# 开发手册（整合版）

## 代码分层

- miniprogram/pages：页面与交互；utils/api.js 统一调用接口，持有本地演示身份时只调用演示后端。
- cloudfunctions/api/index.js：微信云 SDK、真实身份、手机号交换和文字内容检测适配。
- cloudfunctions/api/service.js：身份、权限、事务、聊天、通知、服务及广告管理。
- cloudfunctions/api/domain.js：字段校验与公开用户结构。
- miniprogram/demo/runtime.js：持久化本地仓库、测试身份、单店种子。service.js/domain.js 从服务端生成，仅替换 crypto 依赖。
- database/collections.json：集合与索引人工部署清单；permissions.json 禁止客户端直接访问数据库。
- scripts/check-environment.js：只读核对本地环境参数，不查询云端，不部署资源。

## 业务接口

客户：auth.phone、me、profile.update、services.list、banners.list、chat.open/messages/send/read/rooms。

店员：staff.customers、staff.notifications、staff.readNotifications。通知已读提交 ids 数组（1–20 个），只标记当前员工看到的通知；兼容历史 readAt，但不再推进全局时间水位。

管理员：admin.stores/storeSave、userUpdate、services/serviceSave/serviceDelete、banners/bannerSave/bannerDelete、inspect、qrcode。角色修改撤销目标会话；不能用 userUpdate 授予 admin 或修改现有 admin。

服务管理目前仅支持名称、洗护/家政类别、说明、启停；没有价格、库存、预约、下单或支付。广告最多显示五条，按权重排序，支持纯文字、图片和视频。

## 登录与内容检测

开发登录只替代手机号交换，不替代微信 OpenID 身份或后端权限。前端正式版隐藏入口；生产服务端必须删除 DEV_LOGIN，不能只隐藏按钮。

真实云端注册昵称、修改昵称、聊天、广告文字调用内容检测。pass 通过，review/risky 拒绝；接口异常或没有有效结果返回 CONTENT_UNAVAILABLE，页面保留输入供重试。未实现图片/视频内容检测与人工审核流，不能宣称内容治理全部完成。

本地演示不调用微信内容检测，不证明该平台能力可用。测试有独立的云适配器异常覆盖。

## 素材边界

演示使用本地临时媒体地址，不上传云存储。真实环境保存时上传到 banners/；上传成功但保存失败时保留 fileID，重试复用。

删除或替换广告只修改数据库引用，不直接删除素材，以免误删其他广告共用文件。管理员后续核对无引用文件再清理，会有存储占用；当前没有自动回收任务。

云存储默认客户端不可写。云端媒体上传仍需完成仅管理员可上传的授权方案与真机验收；不得为了试通而全局开放客户端写入。当前可先验收纯文字广告和本地媒体预览。

## 回归要求

运行 npm run demo:sync、npm test、npm run check。测试覆盖页面到服务字段、角色隔离、单店演示 CRUD、聊天分页/已读、事务回滚、环境检查和内容检测失败；云数据库、媒体访问权限、真实平台接口仍需联调。
