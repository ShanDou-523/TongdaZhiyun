# 手机号授权隐私配置排查

## errno:112 的含义

`getPhoneNumber:fail api scope is not declared in the privacy agreement` 表示当前 AppID 生效的《用户隐私保护指引》没有声明手机号接口对应的信息类型。拦截发生在微信手机号授权阶段，尚未取得交给云函数兑换的 code。

## 公众平台配置

1. 登录 [微信公众平台](https://mp.weixin.qq.com/)，确认小程序 AppID 与 `project.config.json` 一致（当前为 `wx7c921a005341718e`）。
2. 进入「设置 → 服务内容声明 → 用户隐私保护指引」，新增或更新指引。
3. 添加手机号信息类型。用途可按当前实际功能填写：“用于账户注册、登录身份验证，以及所属门店提供服务和联系用户。”按界面提示完成对应声明。
4. 同时如实填写本项目实际处理的昵称、园区、可选性别及聊天内容，并提供真实运营主体、隐私联系渠道。不要勾选“未采集隐私”，也不要声明尚未使用的定位、相册等能力。
5. 提交并确认声明生效；如界面有审核要求，按后台状态完成。官方文档说明补充隐私类型声明在 5 分钟后生效。
6. 在开发者工具清除授权数据并重新编译，重新勾选本地隐私说明，点击手机号授权，按微信官方隐私弹窗完成同意，再在真实微信客户端测试。

## 代码处理

- 保留 `app.json` 的 `__usePrivacyCheck__: true`。
- 没有注册自定义 `wx.onNeedPrivacyAuthorization` 处理器，由微信按需展示官方隐私授权弹窗；不需要为本次错误额外添加自定义弹窗。
- 本地 checkbox 表示业务同意，不能代替公众平台信息类型声明或微信记录的隐私授权。
- 注册页识别 errno 112、未声明隐私类型、隐私接口被停用，以及用户未同意隐私协议的错误，给出对应提示；无有效 code 时不请求注册接口。
- 调整云环境 ID、关闭隐私检查或给 `app.json.permission` 随意添加手机号权限，都不能补齐公众平台声明。
- 页面内「隐私说明 → 查看微信平台隐私保护指引」可用于检查是否能打开平台协议。
- `miniprogram/config.js` 的 `privacyOperator`、`privacyContact` 仍待填写真实资料，不能用示例值替代。

## 验证边界

本地回归测试验证错误提示和失败时不调用后端，无法修改或验证公众平台声明。后台配置完成后才能确认该错误已经消除。

参考：[微信官方小程序隐私协议开发指南，第五、六节](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/PrivacyAuthorize.html)。
