# 服务分类测试验收

1. 在微信开发者工具右键 cloudfunctions/api，上传并部署：云端安装依赖。目标仍为个人开发云环境，保留 DEV_LOGIN=1。
2. 重新编译小程序，以管理员登录，在管理中心「服务」点击「补齐全部服务价目表」。共66项，分批导入；更新同编号服务的价目，其他服务和历史订单保留；仅开发云环境允许此操作。
3. 客户从首页洗护进入四个子分类，选衬衫→普通精洗→数量2，应显示80元；窗帘2.35㎡应显示23.50元。选择飞毛腿后费用为0。
4. 家政选择2小时深度保洁，金额119元，预约未来日期与时间。应默认带出宿舍地址，不出现送到门店选项。
5. 门店工作台或管理中心进入「查看与处理订单」，核对服务规格、数量、金额、预约、宿舍号、电话与备注，接单后完成。家政不能进入跑腿大厅；洗护跑腿单要先由骑手送达门店再接单。
6. 客户「我的订单」查看进度与价格；未进入服务前可以取消。

金额为基础服务报价，不代表付款完成。特殊处理、半皮革等附加费暂不自动计算。管理中心可改名称说明与上下架，规格价格当前由测试价目表维护，再次导入会更新为本价目表价格。正式上线前需确认最终价格和服务范围；当前导入入口仅在开发云环境开放。
