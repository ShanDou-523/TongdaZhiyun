# 开工指南（2026-09-21 整合版）

本版整合 GitHub 提交 d15166c 和本地消息修复、单店演示、环境检查。实际经营按一家门店；洗护和家政均在开发范围内。当前只完成基础业务，订单、支付和履约尚未完成。

## 先体验

1. 微信开发者工具导入项目，重新编译，进入本地演示页。
2. 五个身份：客户 A、客户 B、两名同店员工、管理员；只有一家初始门店。
3. 客户发消息，切换员工回复，再切回客户；管理员可维护服务和首页广告。
4. 测试注册选择“其它”并填写位置；测试资料修改和通知已读。
5. 演示数据仅在本机保存，重启保留，主动重置才恢复。图片/视频是临时预览，重启或临时文件过期后需要重新选择。

## 个人云环境联调

从演示页点“进入云端登录 / 联调”，退出本地身份。前端 devLogin=true 且运行于开发/体验版时显示开发登录；服务端还必须设置 DEV_LOGIN=1。实际写入个人云数据库，不使用真实客户资料。

同一微信 OpenID 绑定一个账号和测试手机号，不能通过更换号码切换身份。多设备联调用不同微信；单机多角色测试用本地演示。管理员可给已注册客户分配店员角色，但不能通过该接口授予管理员。

详细配置见 [环境切换清单](环境切换清单.md)。云端当前数据性质、已部署版本和环境变量仍需现场核验，本地测试通过不代表云端已更新。

## 改动后的检查

运行 npm run demo:sync、npm test、npm run check、npm run env:check:dev。生产配置单独运行 npm run env:check:prod；缺少公司信息或开发开关未关闭时应失败。

修改 cloudfunctions/api/service.js 或 domain.js 后必须同步本地演示副本。不要维护第二套 mock 后端。变更记录写入 CHANGELOG.md，按实际验证结果记录，不把模拟结果写成真机验收。

## 协作方式

每次开始先确认分支与 Git 状态，使用明确提交号讨论和部署；整合分支验收后再推送协作。禁止用一边的文件直接覆盖另一边的修改，禁止强推覆盖历史。公司环境切换原则见 [环境边界与上线切换](环境边界与上线切换.md)。
